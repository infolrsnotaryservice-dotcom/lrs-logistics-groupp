TO UPDATE EXISTING GITHUB REPOSITORY:
1. Unzip this archive.
2. Open your GitHub repository, upload the files INSIDE this folder (not this ZIP), preserving assets/. Commit changes.
3. Delete old editor.js in the repository (it is no longer used). Delete the originally uploaded ZIP if present.
4. Verify your Pages deployment then hard refresh the website (Cmd+Shift+R in Safari if supported, or Safari > View > Reload Page From Origin).
5. Submit a test message on the live URL.

You can update HTML using the GitHub editor; browser-local edit bars are intentionally removed from the public site.
